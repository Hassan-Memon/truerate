## How the ideas connect

1. **TrueRate, the site** (this repository) shows every source for a rate and how far they disagree. Its next planned step is the State Bank rate ladder. See the main [`README.md`](../README.md).
2. **The fair-price check** would use that ladder to tell a person how much they lose on a real deal.
3. **The fee-only exchange company** would use TrueRate as its published reference rate.

The product and business ideas are kept here so that nothing is lost and can be picked up again later.
